# ⚽ Análisis de Salarios de Fútbol

## 📊 Descripción del Proyecto
Análisis completo de datos salariales de jugadores de fútbol profesional utilizando técnicas de ETL, EDA y respuesta a preguntas de negocio estratégicas.

## 🎯 Objetivos del Análisis
- Realizar proceso ETL completo sobre dataset de salarios
- Ejecutar análisis exploratorio (EDA) detallado
- Responder 3 preguntas de negocio con evidencia estadística
- Identificar patrones y tendencias en el mercado futbolístico

## 📈 Preguntas de Negocio Respondidas
1. **¿Qué ligas tienen los salarios promedio más altos?**
2. **¿Cómo se relaciona la edad con el nivel salarial?**
3. **¿Existe diferencia salarial entre nacionalidades?**

## 🛠️ Tecnologías Utilizadas
- **Lenguaje**: Python 3.x
- **Librería principal**: Pandas
- **Entorno**: Google Colab
- **Dataset**: Football Salaries Dataset de Kaggle
